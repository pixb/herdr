# Herdr Sixel fork

This branch (`pixb`) is a fork build of [herdrdev/herdr](https://github.com/herdrdev/herdr)
that adds a Sixel pane graphics transport. Upstream Herdr documents Kitty
graphics as its image path; this fork makes pane programs that emit Sixel
render on Sixel-only outer terminals such as `foot` on Wayland.

`pixb` never publishes to the canonical repository. The upstream conversation
lives in GitHub Discussions, and the intake rules in `CONTRIBUTING.md` decide
what happens upstream.

## What works here

- `lf` previews render in a pane on `foot`: `lf` → `chafa` → pane PTY → relay →
  outer terminal paint.
- A pane answers Device Attributes with the Sixel feature, so Sixel-speaking
  programs emit Sixel inside a pane instead of falling back to a protocol the
  outer terminal cannot show.
- Relay frames are sized from the cell pitch the host terminal reports, painted
  on the cells the placement names, and re-emitted behind pane text that
  overwrites them.
- Pacman and AUR installs are detected as package-manager-managed installs, so
  `herdr update` refuses to replace the packaged binary and prints the
  package-manager update instruction.

## Build

Normal Rust build, with one pin: the vendored `libghostty-vt` builds with Zig
0.16.0, and the Zig Arch currently ships is rejected by that build.

```bash
export ZIG=/path/to/zig-0.16.0/zig
cargo build --release --locked
```

Validation commands used on this branch:

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo nextest run --no-fail-fast
```

`just check` and the repo's release recipes are maintainer tooling and are not
run from this fork.

## Arch User Repository

```bash
yay -S herdr-sixel      # or build packaging/aur/herdr-sixel with makepkg
```

The package source lives in `packaging/aur/herdr-sixel/`. It pins Zig 0.16.0
from the official tarball, installs `/usr/bin/herdr-sixel`, and ships
`LICENSE`, `CHANGES`, and `THIRD-PARTY-NOTICES.md` under
`/usr/share/{licenses,doc}/herdr-sixel/`. The package `provides` and
`conflicts` with `herdr`, so it is an opt-in replacement, not an invisible one.

Preview images need an encoder that produces Sixel. The `scope` preview script
used with `lf` calls `chafa -c full --dither none`; `-c 256` for Sixel output
quantizes to the fixed DEC 256 palette and renders gradients as a coarse block
grid.

## License compliance

Apache-2.0. A distribution of this tree ships:

- `LICENSE` — the unmodified Apache-2.0 text.
- `CHANGES` — the section 4(b) notice listing what this fork modified.
- `THIRD-PARTY-NOTICES.md` — generated by `scripts/fork/third_party_notices.py`;
  regenerate it after any dependency change.

`scripts/fork/third_party_notices.py` is fork tooling. It is not part of the
upstream build and does not run in the upstream release pipeline.
